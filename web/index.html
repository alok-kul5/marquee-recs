    How a request flows

    Input

    History + context

    Last 50 films, genre profile, age, gender, occupation, hour and weekday.

    Stage 1 · Retrieval

    Two-tower → HNSW

    PyTorch user and item towers trained with in-batch softmax and logQ correction. FAISS HNSW returns 150 films; ALS and trending add more.

    Stage 2 · Ranking

    LightGBM LambdaRank

    23 features per pair: retrieval scores, kNN and ALS affinity, freshness, popularity, genre match.

    Output

    Top-K + reasons

    Seen films are filtered out, and each pick is tied to the liked film closest to it in embedding space.
